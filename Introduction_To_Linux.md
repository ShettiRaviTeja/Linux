# Introduction To Linux
- Linux is based on the UNIX operating system, a multi-user and multitasking platform developed in the 1970s.
- UNIX is nothing but an operating system just like windows, that helps users interact with a computer, manage files and execute programs.
- Key features of UNIX:
  - Multiuser: Multiple users can use the system.
  - Multitasking: Multiple tasks can run simultaneously.
  - Security: Provides user permissions and access control.
  - Portability: Can run on different hardwares.
  - File Management: Helps create, delete and manage files.
- Linux is free and open-source, encouraging global collaboration and innovation while providing strong security, flexibility, and reliable performance across different devices and industries.

## Why Linux is more powerful and widely used than windows?
- Linux is considered powerful and widely used because it is free, open-source, secure, stable, flexible, and highly customizable.
  1. Open Source: Anyone can access, modify, and distribute its source code.
  2. Free: Most Linux distributions are available free of cost.
  3. Security: Provides strong permission management and is generally less targeted by malware.
  4. Stability: Can run for long periods without requiring frequent restarts.
  5. Performance: Can run efficiently with fewer system resources.
  6. Customization: Users can customize the operating system according to their requirements.
  7. Command Line: Provides powerful command-line tools for automation and system administration.
 
## Distributions in Linux
  - Distributions in Linux is nothing but the different versions of Linux that are developed by combining kernal with system utilities, software packages, and applications to provide a complete operating system.
    - Ubuntu: It is a beginner-friendly Linux distribution used for desktops, servers and cloud computing.
    - Red Hat Enterprise Linux (RHEL): Enterprise Servers
    - Debian: Stability and reliability
    - Fedora: Developer focused Linux distribution with the latest technologies
    - Kali Linux: Cybersecurity, ethical hacking and Penetration testing
    - Deepin: It is a visually attractive Linux distribution with an easy-to-use interface
    - Linux Mint: It is a simple and beginner-friendly Linux distribution for windows users
    - MX Linux: It is a lightweight Linux distribution suitable for older hardware.
    - Solus: Modern Linux distribution focused on desktop performance and simplicity.
    - Manjaro: It is a user-friendly Arch-based Linux distribution with rolling updates.
    - openSUSE: Powerful Linux distribution used for developement and enterprise environments.
